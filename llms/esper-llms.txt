# Esper

> Esper is the DevOps platform for connected devices. The Esper Manage REST API programmatically provisions, monitors, and controls Android-based dedicated devices running the Esper agent — devices, device groups, applications and versions, device/group commands, enterprise/compliance policies, geofences, content, and device event subscriptions. Auth is a per-tenant Bearer API key; an official Python SDK (esperclient) and CLI (espercli) are available. This llms.txt is generated by API Evangelist from the provider's public developer surface.

## APIs

- [Esper Manage API reference](https://api.esper.io/openapi): REST API for device, group, app, command, policy, geofence, content and subscription management. Base URL: https://<domain>-api.esper.cloud/api
- [OpenAPI spec (bundled Swagger 2.0)](openapi/esper-manage-openapi-original.yml): 62 operations, bundled from github.com/esper-io/esper-api-spec.
